# Bucket 10 — E-drum and drum-machine primary documentation

Read `.agents/round2/BRIEF.md` first. It defines the three-round method, the axis
model and the output structure. Follow it exactly.

## What this bucket must cover

- Roland Data List PDFs, which carry the factory note maps, for TD-17, TD-27, TD-50, TD-50X, TD-07, TD-02, VAD series, SPD-SX Pro, SPD-30, TM-6 Pro, HandSonic HPD-20. Direct PDF paths 403; try the Roland knowledge base articles, the support pages, and the Wayback Machine.
- Roland MIDI implementation charts and MIDI implementation sections, which name the pad zones and the hi-hat controller behaviour normatively.
- Yamaha Data Lists for DTX-PRO, DTX-PROX, DTX6/8/10, DTX900, DTX700, DTX502 and the DTX-Multi 12.
- Alesis, 2Box, ATV, EFNOTE, GEWA, Pearl Mimic Pro, Simmons, Millenium reference guides.
- Drum machine service manuals and owner's manuals: TR-808, TR-909, TR-707, TR-606, TR-626, TR-8S, R-8, Linn LM-1 and LinnDrum, Oberheim DMX, E-mu SP-1200, Alesis SR-16, Yamaha RX5, Korg Volca Beats, Elektron Analog Rytm and Machinedrum.
- Roland patents and service notes for the 808 and 909 voice circuits, which name the voices canonically.

## Note on this bucket

The deliverable is the ZONE and VOICE terminology plus the controller behaviour, not the note numbers - note numbers are Phase 3. Also record, per document, whether it is officially downloadable, so Phase 3 knows where to go.
