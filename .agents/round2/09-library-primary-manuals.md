# Bucket 09 — Sample-library manuals, first-hand

Read `.agents/round2/BRIEF.md` first. It defines the three-round method, the axis
model and the output structure. Follow it exactly.

## What this bucket must cover

- Toontrack Superior Drummer 3 - the operation manual and its key-map appendix; EZdrummer 3; the EZX and SDX documentation that lists articulations per instrument.
- XLN Audio Addictive Drums 2 - the official keymap PDF and the manual.
- FXpansion / inMusic BFD3 and BFD Player - the manual's key-map reference and its articulation naming.
- Steven Slate Drums 5 and 5.5 manuals.
- Native Instruments Studio Drummer and Abbey Road Drummer manuals - NI publishes full articulation vocabularies.
- GetGood Drums documentation, ML Sound Lab ML Drums, IK Multimedia MODO Drum, Power Drum Kit, MT Power Drum Kit 2, Sennheiser DrumMic'a.
- Rayzoon Jamstix 4 manual appendices B and C, already partly extracted - verify and complete.
- Any library that publishes a downloadable drum map, note-name file or pitch list OFFICIALLY, as opposed to a community transcription.

## Note on this bucket

Round 1 used community transcriptions for most of these. Go to the vendor PDFs. Where a PDF 403s, try the vendor knowledge base, the Wayback Machine and the vendor's support site. Report exactly which are officially published and which are not.
