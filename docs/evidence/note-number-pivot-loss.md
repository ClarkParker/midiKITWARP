# Evidence: the cost of a note-number pivot

Generated by `python -m tools.iom.analyze data/legacy-iom`. Do not edit by hand.

Each `.iom` file maps a foreign layout onto the host's internal layout. That internal
layout is the pivot, and it is a MIDI note number. Where two source notes share one
target, a distinction is destroyed on the way in and no inversion can recover it.
